## Overview

A small sample app used as the plugin's end-to-end regression target. The home page links to an item list, and the item list renders whatever the items API returns.

## Requirements

1. The home page shows the title "Sample app" and an "Items" link to the item list page.
2. The item list page requests `GET /api/items` once on load and renders one list entry per returned item, labelled with the item's `display_name`.
3. Selecting the "Items" link on the home page opens the item list page.
