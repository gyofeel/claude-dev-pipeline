## 개요

플러그인 E2E 회귀 대상으로 쓰는 작은 예제 앱이다. 홈 화면에서 아이템 목록으로 가는 링크가 있고, 목록 화면은 아이템 API 응답을 그대로 그린다.

## 요구사항

1. 홈 화면에 "Sample app" 제목과 아이템 목록 화면으로 가는 "Items" 링크를 보여 준다.
2. 아이템 목록 화면은 진입할 때 `GET /api/items` 를 한 번 부르고, 응답의 아이템마다 목록 항목을 하나씩 그린다. 항목 이름은 `display_name` 이다.
3. 홈 화면에서 "Items" 링크를 누르면 아이템 목록 화면이 열린다.

## 수용 기준

- [ ] **AC-01**: 홈 화면에 "Sample app" 제목이 보이고 콘솔 에러가 없다.
- [ ] **AC-02**: 아이템 목록에 API 응답의 아이템마다 항목이 하나씩 보이고, 항목 이름은 `display_name` 이다.
- [ ] **AC-03**: 홈 화면에서 "Items" 링크를 누르면 `/list.html` 로 이동하고 아이템이 보인다.
