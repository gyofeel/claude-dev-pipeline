## Overview

운영자가 공지사항 목록을 조회하고, 중요한 공지를 상단에 고정하고, 게시 기간을 정한다.

## Requirements

1. 목록은 게시 시작일 내림차순으로 20건씩 보여준다.
2. 상단 고정 공지는 최대 3건이며 목록 맨 위에 따로 묶는다.
3. 게시 기간의 종료일은 시작일보다 앞설 수 없다.

## Acceptance Criteria

- [ ] **AC-01**: 목록에 들어가면 게시 시작일 내림차순으로 20건을 보여준다.
- [ ] **AC-02**: 고정 공지가 3건인 상태에서 [상단 고정]을 누르면 고정하지 않고 "상단 고정은 3건까지 가능합니다."를 표시한다.
- [ ] **AC-03**: 종료일을 시작일보다 앞으로 잡고 저장하면 저장하지 않고 "종료일은 시작일 이후로 설정해 주세요."를 표시한다.
- [ ] **AC-04**: 조회 결과가 없으면 빈 목록 안내를 보여준다.
